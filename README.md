# SchoolFlow

A starter Next.js build of the SchoolFlow student dashboard.

## Run locally

1. Install Node.js.
2. Run `npm install`
3. Run `npm run dev`
4. Open http://localhost:3000

## Deploy

Upload this project to a GitHub repository, then import the repository into Vercel.

## Current features

- Weekly schedule
- Add schedule events
- Assignment tracker
- Mark assignments complete
- Basic study-priority recommendation
- Responsive layout
